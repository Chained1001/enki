# 模板字段审查：从作家与编辑视角看拆书产物的可用性

| 字段 | 值 |
|---|---|
| 状态 | 稳定 |
| 版本 | v1 |
| 最后更新 | 2026-10-23 |
| 审查对象 | `skills/book-breakdown/assets/` 全部 20 份模板 ＋ 13 份 references 策略件 |
| 审查视角 | 网文作者（要照着写出下一章）、责编／主编（要判断这本书能不能签、能卖多少） |

## 一、结论先说

你的直觉是对的，而且问题比「全书大纲缺人物动机」更深一层。

**根本问题不是「字段太少」，而是模板整体是按「图书管理员的分类学」搭的，不是按「作者的决策需求」搭的。**

这三份模板的质量参照系完全不同：

- **逐章记录、伏笔台账** 是按**数据表**设计的——一行一章／一条一伏笔，列名明确，可统计。这两份是全书最好的模板。
- **人物卡、金手指、地点卡** 是按**档案卡**设计的——「脱离原文仍可调用」。基本成立。
- **全书大纲、卷纲、幕纲** 是按**结构标签**设计的——段名、段型、九节点。**这一层基本没有回答「作者拿它能干什么」。**

从作家角度问一句就能测出来：**「我读完〈全书大纲〉，能开始写第二章吗？」** 现在的答案是「不能」——它告诉你九节点落在第几章，却不告诉你主角想要什么、他为什么非要不可、谁在阻止他、读者为什么关心。

从编辑角度问一句：**「我读完这套产物，能判断这本书该不该签、卖点是什么、对标哪本吗？」** 现在也是不能——20 份模板里，「读者」只出现 3 次（且都在别处），「追读／留存／付费／卖点／主题」几乎为零。

**评分**

| 维度 | 分 | 理由 |
|---|---|---|
| 结构骨架完整性 | 4/5 | 四层骨架＋台账＋九节点，骨架层是齐全的，这在同类项目里少见 |
| 可仿写性（作家视角） | 2/5 | 有「发生了什么」，缺「为什么有效」与「我该怎么写」 |
| 商业判断力（编辑视角） | 1/5 | 无主题、无卖点、无读者预期、无对标、无数据面 |
| 人物维度深度 | 2/5 | 三要素／面具／反派三层写在策略里，模板无字段承载 |
| 情绪与节奏落地 | 2/5 | 策略定义了爽点循环、章末钩分型，模板无列可落 |
| 跨模板一致性 | 3/5 | 主干能对上，但多处策略承诺的字段在模板中空挂 |
| **综合** | **2.3/5** | **「编目合格，可用性不足」** |

## 二、最要紧的一条：策略写了，模板没接

这是本次审查最重要的发现，因为它证明**缺口不是设计取舍，是落地漏了**。项目自己的方法论已经想清楚了，只是没给字段。

### 2.1 爽点：策略里是核心，模板里零字段

`references/幕与节奏策略.md` 把爽点当作节奏的主轴：

- L5：「幕级判定之后的内容环节：五拍核对、弧型归类、**爽点**与钩子、情绪与节奏」
- L13 S-03「**爽点循环记账**：记『破案/打脸→立功/震惊→升赏/收获』的循环链与**周期章数**；循环断点即节奏转折」

但实测：**20 份模板里「爽点」出现 0 次**，「逐章记录」九列（章号/标题/视角/地点/出场/一句话事件/剧情线/伏笔/情绪）也没有爽点列。

后果很直接：S-03 要求算「周期章数」，**而没有任何一列记录爽点发生在哪一章**。这条策略在产物上不可执行。一个作者想学「这本书多少章一个爽点」，翻遍产物也查不出来——这不是字段不够，是**方法论承诺了、产物交不出**。

### 2.2 卷纲「节奏段」：策略点名要写入，卷纲没有这一段

`幕与节奏策略.md` L18 S-08 原文：「均章长逐卷漂移、连续钝收、情绪长期单值——**记入卷纲节奏段**」

实测 `卷纲模板.md` 八个段名：卷命题与目标／主要冲突／事件弧清单／关键事件链／人物弧线／伏笔埋设与回收／新地图与新设定投放／卷末收束与悬念定格。

**没有「节奏」段，也没有任何能承载节奏异常的位置。** S-08 的产出无处可写。

### 2.3 人物三要素：策略的第一条，人物卡没有字段

`人物提炼策略.md` L11 S-01 是全文件的**第一条策略**，也是它自己定的立卡标准：

> 「从原文反推**外在目标**（要什么）、**内在缺口**（缺什么）、**致命弱点**（会毁在哪）；**三要素齐则人物卡立得住**」

实测 `人物卡模板.md`：外在目标 0、内在缺口 0、致命弱点 0、动机 0、目标 0、弱点 0、面具 0、恐惧 0、秘密 0。

同一份策略里还有 S-04「面具与真相」、S-07「反派三层（人性＋理念＋源头）」，模板同样一个字段都没有。

**「三要素齐则人物卡立得住」——但卡片上根本没有填三要素的地方。** 这已经不是缺字段，是**模板与它自己的验收标准互相矛盾**。

### 2.4 章末钩分型：策略定义了四型，模板只有一格散文

`幕与节奏策略.md` L14 S-04：「钩型四分：危机、悬念、期待、反差；高潮后的余波章允许钝收…**连续两章以上钝收才标拖**」

「连续两章以上」是一个**可以脚本化检测的条件**——但逐章记录没有「章末钩型」列，无法做连续性判定。`开篇三章模板` 里倒是有「钩型：危机／悬念／期待／反差」，但那只覆盖前三章。

于是「连续钝收」这条全书画像级的判断，全书只有前三章有数据。

### 2.5 策略承诺 vs 模板承载：一览

| 策略条目 | 要求产出 | 模板承载 | 状态 |
|---|---|---|---|
| 幕与节奏 S-03 爽点循环记账 | 循环链＋周期章数 | 逐章记录无爽点列 | ✗ 空挂 |
| 幕与节奏 S-04 章末钩分型 | 四型＋连续钝收检测 | 逐章记录无钩型列 | ✗ 空挂（仅开篇三章有） |
| 幕与节奏 S-08 节奏异常标注 | 写入卷纲节奏段 | 卷纲无节奏段 | ✗ 空挂 |
| 人物提炼 S-01 三要素 | 外在目标/内在缺口/致命弱点 | 人物卡无字段 | ✗ 空挂 |
| 人物提炼 S-04 面具与真相 | 表层人设 vs 深层动机 | 人物卡无字段 | ✗ 空挂 |
| 人物提炼 S-07 反派三层 | 人性/理念/源头 | 人物卡无字段 | ✗ 空挂 |
| 人物提炼 S-08 认知水位 | 三方认知差异 | 无字段 | ✗ 空挂 |
| 结构拆解 S-06 蓄势段 | 各线推进记录 | 骨架段型有「蓄势段」，无推进子表 | △ 半挂 |
| 设定提炼 S-02 力量体系三变量 | 门槛/通道/天花板 | 专题模板无这三个字段 | △ 半挂 |
| 文风 S-04 潜台词密度 | 密度计量 | 定量指纹七项无此项 | △ 半挂 |

**10 条核心策略中有 8 条在模板层没有落点。** 这说明问题不是零散的，而是**方法论与产物模板之间缺了一道「字段推导」工序**——策略写「要考虑 X」，没人负责把 X 变成「模板上的第 N 列」。

## 三、全书大纲：你说的动机缺口，以及它背后更大的问题

### 3.1 现状

`全书大纲模板.md` 只有三块：核心冲突装置（3 字段）、全书骨架段清单（4 列表）、九节点检查单（3 列表）。

**「主角」出现 0 次，「动机」0 次，「主题」0 次，「对手」0 次，「结局」0 次。**

### 3.2 你说得对，但缺的不止动机

从作家角度，全书大纲是**唯一一份「开写前必须想清楚」的文件**。编辑看一本书的大纲，关心的顺序是：

1. **这本书讲什么**（主题／母题）—— 模板没有
2. **谁的故事**（主角）—— 模板没有，全书大纲通篇不提主角
3. **他想要什么、为什么非要不可**（动机／欲望）—— 模板没有
4. **谁不让他要**（对手／阻力）—— 模板没有
5. **读者为什么会一直看**（读者承诺／期待管理）—— 模板没有
6. **最后他变成什么样**（人物弧光终点）—— 模板没有
7. 靠什么装置驱动 —— **模板有**（核心冲突装置）
8. 分几段、节点落在哪 —— **模板有**（骨架段＋九节点）

也就是说，**编辑看大纲的前六个问题，模板一个都答不了；模板答的两条，恰好是第七、第八位的问题。**

这不是「少了一两个字段」，是**整份文件的立足点偏了**：它现在是一份「结构测量报告」，而不是「故事设计书」。

### 3.3 一个具体反例

拿「核心冲突装置」这一块看：它记「装置名称／首次出现章／结构功能」。这是**分析者视角**——我在给这本书的装置做解剖。

作者要的是**设计者视角**：这个装置为什么能撑起一千万字？它的「产出」是什么（每次启动给主角什么）？它的「成本」是什么（用一次付什么代价）？它什么时候会失效（读者什么时候会腻）？

现模板把装置当**标本**记，而不是当**引擎**记。两者都能写「装置名称：X」，但后者才能回答「我能不能用这个装置写我的书」。

### 3.4 建议补的字段（按编辑关注顺序）

| 补什么 | 为什么 | 从哪来 |
|---|---|---|
| 主题／母题（一句话） | 编辑判断「这本书想说什么」的第一入口；也决定结局该往哪收 | 需新增策略 |
| 主角一句话（谁·要什么·卡在哪） | logline，全书大纲第一行就该有 | 需新增策略 |
| 主角核心欲望与恐惧 | 全书所有情节的发动机 | 已有 S-01 三要素，未上模板 |
| 主要对手与对抗结构 | 没有对手就没有冲突，现有「核心压力源」在卷层，全书层缺失 | 证据支持（见 3.5） |
| 人物弧光终点（起点→终点一句话） | 编辑判断「这本书有没有成长线」 | 部分在主角解构，未上大纲 |
| 读者承诺（读者点进来期待看到什么） | 网文商业性的核心，缺此无法判断卖点 | 需新增策略 |
| 结局形态（HE/BE/开放式｜爽感结算方式） | 决定读者口碑与完读率 | 需新增策略 |

### 3.5 关键证据：项目自己的反推记录已经指出了这些列

这不是我凭空加的。`docs/产品/模板反推/证据/《诡秘之主》-反推记录.md` 明确写：

> 「一行一卷，本书实际可稳定填出的列：1.卷序号 2.卷名 3.名称来源…8.**主要对手（本卷主反派）**…」

> 「推断补充列（本书证据不足以成为必选，但值得候选）：**主视角占比**（第六部大量让渡视角）、伏笔埋/收清单指针。」

`《大奉打更人》-反推记录.md` 更直接：

> 「每幕都可稳定填出：起止章 / 幕型 / 核心事件链 / **对手** / 地点 / 主角状态与所得 / 幕末钩子 / **情绪基调（爽|虐|燃|喜）**」

**对照现状：幕纲模板「对手」0 次，「反派」0 次。**

也就是说：**项目自己在反推真书时，明确认定「对手」是每幕都能稳定填出的字段；但落到模板时，这个字段丢了。** 分卷总表倒是把「主要对手」合并成了「核心压力源」——这是《我真没想重生啊》的合理修正（情感文无外敌），但**不该因此把「对手」从幕纲一起删掉**：大奉是案件流，每幕必有对手；重生是情感流，可以不填。正确做法是「对手（可为空，情感流写压力源）」，而不是整列消失。

这是**用一本特殊书的口径，覆盖掉了另外几本的一般需求**。

## 四、逐模板审查

### 4.1 全书大纲模板

见第三节。补充两点：

- **「九节点检查单」与「骨架段清单」严重冗余**：骨架段的「段型」枚举（开篇钩子／日常铺垫／转折／升级扩张／中点反转／蓄势段／低谷／反攻或自救／高潮／收束余韵）与九节点（开篇钩子／日常铺垫／第一次转折／升级扩张／中点反转／低谷与代价／反攻或自救／高潮／收束余韵）**几乎是同一组词**。两份表都带章号，必然错位维护。
- 更严重的是：**项目自己的证据否定了九节点作为分段**。诡秘反推记录写「九段式若强制等分会产生大量空段；保留为『全书节点检查单』正合适」，并给出实际骨架是「8 部两层嵌套」。现在的模板把「8-12 段骨架」和「9 节点」并列，等于同时保留了两套互斥的分段法，却没有规定两者冲突时以谁为准。

**建议**：九节点降为骨架段清单的**可空校验列**（节点名默认空），或明确写「骨架段优先，九节点仅作缺失检查，不强制一一对应」。

### 4.2 分卷总表模板

相对成熟，是本书最好的一份之一。问题：

- **13 列对「一行一卷」而言过宽**。诡秘 8 卷还好；诡秘类长书 8 行×13 列尚可，但**每列都是长文本（一句话钩子、核心压力源、主角状态变化、卷末状态）时，表格在 Markdown 里已经不可读**。建议拆分：核心 8 列留表，长文本列转「每卷小节」。
- 「时间跨度（可选）」「卷结构型与商业外证（可选）」两列带「（可选）」后缀，**与校验器全等比较冲突**（见上一份审查报告 M-03）。
- 「**商业外证**」这一列方向极好——它是全书唯一触碰「这卷商业表现」的地方（诡秘证据里对应「更新期追订/均订」）。但只有卷级、且是可选列，**没有升格为全书级的判断依据**。这是编辑视角最该加强的地方，现在是最弱的一环。
- 缺「本卷主要对手」——被合并进「核心压力源」了，但见 3.5，两者不该互斥。

### 4.3 卷纲模板

- **无「对手」段**（证据显示应可填）。
- **无「节奏」段**（S-08 点名要写进来，见 2.2）。
- 「事件弧清单」表有「弧型／五拍完成度」但**没有弧编号**——导致幕纲「与卷纲的对应」只能写散文，无法做外键校验。
- 「人物弧线」只写「主角状态轴引用＋本卷配角弧」，**没有「本卷谁变了、从什么变成什么」的明确结构**。作者最想学的就是「配角在什么节点被撬动」。
- 缺「本卷读者期待管理」：开卷抛什么期待、卷中兑现多少、卷末留什么。这是「追读率」的机制层，缺失后无法解释「为什么这卷好看／难看」。

### 4.4 幕纲模板

- **无「对手」段**（证据显示每幕可稳定填出，见 3.5）。这是幕纲最大缺口：一个「事件弧」的本质就是「主角 vs 谁／vs 什么」，没有对手字段，幕纲退化成一串事件。
- 「主角所得与状态变化」只记"所得"，**不记"所失"**。人物提炼策略 S-03 明确「弧光成立的检验是『得到与失去并存』」，模板没有记账的地方。
- 「情绪基调与走向」**只有扬/抑/震荡三值，没有强度**。大奉证据给的是「爽|虐|燃|喜」——**这是四型情绪而非三值方向**，且「燃」和「爽」的强度信息在三值制里完全丢失。结果：画不出情绪曲线，跨幕不可比。
- 缺「本幕爽点／兑现点」：一个事件弧最该记的是「读者在这一幕得到了什么满足」。
- 缺「视角分配」：诡秘证据明确「视角分配（多线书必需）」是幕纲增列候选，现模板没有。

### 4.5 人物卡模板——问题最集中的一份

现有 11 个字段，绝大多数是**身份信息**（姓名、别称、势力、坐标、出场章、章节链、关系、说话风格、原型词、结局、金句）。

**这是一个「户口本」，不是「人物设计图」。**

缺失的、且被策略明确要求的：

| 缺什么 | 策略出处 | 后果 |
|---|---|---|
| 外在目标（要什么） | 人物提炼 S-01 | 不知道这个人物在故事里追求什么 |
| 内在缺口（缺什么） | 人物提炼 S-01 | 不知道他为什么非要不可 |
| 致命弱点（会毁在哪） | 人物提炼 S-01 | 不知道他会在哪里失败，无法预判转折 |
| 面具与真相 | 人物提炼 S-04 | 表层人设与深层动机分离，高光章无处定位 |
| 反派三层（人性/理念/源头） | 人物提炼 S-07 | 反派只有「功能位」标签，没有动机逻辑 |
| 认知水位（角色知道什么/读者知道什么） | 人物提炼 S-08 | 信息差驱动型书的核心机制无法记录 |

**「原型词/功能位」这个字段尤其可惜**：它记「如白月光、宝藏、告密者、学生会主席」。这个字段是**标签**，不是**设计**。标签告诉你「他是告密者」，但不告诉你「他为什么告密、告密后他失去了什么」。前者是一个词，后者才是可以复用的东西。

### 4.6 主角解构模板——最该补也最快能补

五文件的结构是好的，但：

- **文件四「目标与动机链」只有 want/get 两列，缺「动机」列**。策略 S-02 明确要「动机（为什么）→愿望（想要什么）→目标（具体做什么）**三层贯通**」，模板只做了后两层。而「为什么」才是作者最需要的那一层。
- 文件四缺「代价」列：得到之后付了什么。
- **缺「核心恐惧」与「致命弱点」的独立呈现**——这是人物所有回避行为的源头。
- 整个文件**没有 `## 内容` 段**（20 份模板里唯一一份），与 Q-20「模板统一骨架：概念→契约→内容」不符。
- 文件二「成长轨迹」只有境界/事业/身份，**缺「心理状态」轴**。境界可以升，人可以不成长。

**这是投入产出比最高的补法**：加两列（动机、代价）＋一个文件内的「恐惧与弱点」段，就能让主角解构从「履历表」变成「人物设计图」。

### 4.7 逐章记录模板——数据底座，但漏了三列

九列（章号/标题/视角/地点/出场/一句话事件/剧情线/伏笔/情绪）是全书最扎实的表格。缺：

| 缺列 | 谁需要 | 为什么 |
|---|---|---|
| 章字数 | 节奏分析 | 卷级均章长有，章级没有；「这章为什么觉得短」无法定位 |
| 章末钩型 | 幕与节奏 S-04 | 四型＋连续钝收检测无法执行（见 2.4） |
| 爽点标记 | 幕与节奏 S-03 | 「多少章一个爽点」无法计算（见 2.1） |

另外：「伏笔埋/收」只填自由文本，**不填台账编号**（模板明说「台账编号只在伏笔台账里统一分配」）。这导致逐章与台账之间**没有外键**——一千章的书想查「这条伏笔在哪几章被强化过」，只能全文搜索。

### 4.8 金手指模板——这份质量最高

九段齐全（类型/定义与获得/规则与边界/代价与限制/迭代与成长链/使用记录/叙事职能/隐藏与暴露/与剧情耦合），且「代价与限制」要求「无限制时写『无』并注明依据章」——**这是全项目写得最专业的一份**。

唯一建议：加一段「**强度阶梯**」——金手指在全书各阶段能解决多大问题（对应对手的强度）。这是力量流「爽感递减」问题的根源，现在只能从「迭代与成长链」间接推。

### 4.9 开篇三章模板——方向对，字段偏浅

四项（入场钩子/信息投放/人设立住手段/章末钩）是对的，但：

- **缺「读者承诺」**：前三章最重要的功能是「告诉读者这本书以后会给他什么」。现在的四项全是技巧层，没有承诺层。
- **缺「金手指/核心装置的出场」**：网文前三章必须交代主角凭什么赢，模板完全没有这个字段。
- 「人设立住手段」只有「欲望／困境／反差怎么给出」，**缺「代入感设计」**——为什么读者愿意把自己放进这个角色。
- 「章末钩」有钩型四值，**无强度**（与 4.4 同问题）。
- 「可复用套路 ≥3 条」是好的，但**没有归档位置**——套路应该进一个可跨书累积的库，现在只存在这一本书的产物里，第二本书要重新发现。

### 4.10 伏笔台账——第二好的模板

八列完整（编号/描述/埋点章/强化章/回收引爆章/跨度/涉及实体/状态），且给了「未收/半收/已收/续作预留」四态与「非常规叙事书追加三列」的扩展。

缺：
- **「回收幕」列**：「强化章」有，但回收发生在哪一幕没有，导致台账与幕纲无法对账。
- **「类型」列**：情感伏笔/道具伏笔/身份伏笔的埋法与回收方式完全不同（见《我真没想重生啊》反推：「台灯 96→758→1060 章」是道具伏笔）。不分类则无法总结规律。
- **「重要度」列**：无法区分主线大伏笔与边角料。

### 4.11 世界观模板 / 专题模板

- 世界观六个段（时空/地理/势力/历史/社会文化/世界规则）是**世界百科目录**，不是**设定投放计划**。缺的是「**这些设定按什么顺序、在哪几章告诉读者**」——而这正是「设定倾泻」这个新手最大毛病的解药。
- 专题模板「形态一」五个字段（定义范围/结构层级/揭示节奏/与剧情耦合/与其他设定边界）中，**「揭示节奏」是唯一对作者有直接指导价值的**。其余四个是分类学。
- **缺「门槛/通道/天花板」三变量**（设定提炼 S-02 明确要求，模板无字段）——这是力量体系最核心的三件事。

### 4.12 文风模板——七段里最强的与最弱的

「定量指纹」七项指标由脚本生成、agent 不改写——**这是全项目工程化最好的一处设计**，把主观的「文风」锚定成可复现的数字。

但「原文样本」只有「5-10 段最能代表本书文风的摘录」，**缺「为什么这段有代表性」的注解**。没有注解，样本库就只是文摘，不是可学习的教材。

建议：每段样本加一行「这段示范了什么手法」，把文风从「感受」变成「可指认」。

### 4.13 其他

- **势力卡**：缺「势力对势力的关系」（只有「与主角关系」）。「谁和谁在打」这个最基本的信息，现在只活在世界观一段散文里。
- **地点卡**：质量不错，「进入章≠预告章」这个区分很专业（来自诡秘「神弃之地第 21 章预告、第 1153 章进入」的真实痛点）。缺「地点在剧情中的功能」（是战场、避难所还是信息场）。
- **物品卡 / 概念卡**：字段合理但偏薄。物品卡缺「强度/等级」（对应对手强度）；概念卡缺「与金手指的关系」。
- **报告模板**（快速模式）：明显落后于结构化模式，且**用 `####` 写要素表，导致四段对校验完全不可见**（详见上一份审查报告 2.4）。上一份报告已判定「快速模式已被冷落」，此处不重复。

## 五、从编辑视角看：整套产物缺一整层

这是本次审查最想说的一点。

现在的 20 份模板，回答的全是同一类问题：**「这本书里有什么、怎么排的」**。

但一个责编／主编拆一本书，要回答的是另一类问题：

| 编辑要问 | 现有产物能否回答 | 缺什么 |
|---|---|---|
| 这本书的**卖点**是什么（一句话） | ✗ | 「卖点」20 份模板 0 次 |
| 它的**读者**是谁 | ✗ | 「读者」仅 3 次，无读者画像字段 |
| 它**对标**哪本书、差异化在哪 | ✗ | 无对标机制（PRD 明确「不做跨书对比」，但单本也需要「与同类的差异」） |
| **追读动力**来自哪里 | ✗ | 无追读机制分析 |
| **留存曲线**大致什么形状 | ✗ | 无（卷级「商业外证」是唯一触点，且可选） |
| 开头能不能**过审／过编辑** | △ | 开篇三章有技巧分析，无「能不能签」的判断依据 |
| 结局**读者满不满意** | ✗ | 无结局形态、无完读率相关字段 |
| 这本书**值不值得学**、学哪一段 | ✗ | 无质量分层结论（PRD 非目标是「不判断好坏」，但「哪段值得学」是可判的） |

**这不是要求它做「书评」**（PRD 非目标明确排除了书评）。区别在于：

- 书评 = 「这本书好不好看」→ 主观价值判断，PRD 正确地排除了
- 商业结构分析 = 「这本书靠什么机制留住读者」→ **可观察、可计数、可复现**，属于结构范畴

后者不违反「只还原结构、不判断好坏」的非目标，但**现在是完全空白的一层**。

具体可补的最小集合（都不需要主观判断）：

1. **卷级「商业外证」升为常驻列**：追订/均订/月票（若作者附注有），无则写「无数据」。诡秘证据明确这是可得的。
2. **追读钩盘点**：每卷「读者为什么要看下一卷」的一句话——这是结构判断不是好坏判断。
3. **卖点一句话**：从「核心冲突装置＋主角金手指＋题材」推导，属归纳不属评价。
4. **情绪曲线**：已有情绪三值，缺强度，补强度即可画出全书曲线。
5. **结局形态与结算方式**：HE/BE/开放 + 最后一章怎么兑现读者期待。

## 六、优先级建议

### P0：先修「策略与模板对不上」的硬伤（不改就是自相矛盾）

1. **给逐章记录加两列**：`章末钩型`（危机/悬念/期待/反差，可空）、`爽点标记`（无/小爽/中爽/大爽），让 S-03／S-04 第一次可执行。
2. **给卷纲加「节奏段」**，让 S-08 有落点；或改 S-08 的措辞为「记入幕纲情绪段」。
3. **给人物卡补三个字段**：外在目标／内在缺口／致命弱点（S-01 的立卡标准）；主要配角追加段加「面具与真相」。
4. **给幕纲加「对手」段**——依据在项目自己的两本反推记录里，属回归原设计而非新增。

### P1：全书大纲补齐「故事设计层」（你最初的直觉）

5. 加**主题/母题**（一句）、**主角 logline**（谁·要什么·卡在哪）、**主要对手**、**人物弧光终点**、**读者承诺**。
6. 处理「骨架段清单 vs 九节点」的冗余：九节点降为可空校验列，明确冲突时以骨架段为准。

### P2：编辑视角补一层（新增但不违反非目标）

7. 分卷总表「商业外证」由可选列升为常驻，允许「无数据」。
8. 新增「**卷级追读钩**」列：读者为什么要看下一卷。
9. 新增全书级「**卖点一句话**」与「**结局形态**」。
10. 情绪基调补**强度**（如 爽/燃/虐/喜 × 强/中/弱），或改回大奉证据的四型制。

### P3：补齐其余字段缺口

11. 主角解构文件四加「动机」与「代价」两列，文件二加「心理状态」轴。
12. 事件弧清单加**弧编号**，幕纲「与卷纲的对应」改填编号（可做外键校验）。
13. 伏笔台账加**回收幕 / 类型 / 重要度**三列。
14. 专题模板补**门槛/通道/天花板**三变量。
15. 势力卡补**势力对势力关系**；物品卡补**强度等级**。
16. 开篇三章补**读者承诺**与**核心装置出场**。
17. 文风「原文样本」每段加一行**手法注解**。
18. 主角解构补 `## 内容` 段（唯一的骨架不合规项）。

## 七、一句话总结

**这套模板能让你「查清一本书长什么样」，还不能让你「学会怎么写一本这样的书」，更不能让编辑「判断这本书值不值得签」。**

缺口的形状很清晰：**策略层已经想到了（三要素、爽点循环、钩型、面具与真相），模板层没接住**。所以第一批改动不是「发明新字段」，而是**把项目自己已经写下的方法论落到表格上**——这部分几乎没有争议，而且是投入产出比最高的。

真正的增量在编辑那一层（卖点、追读钩、商业外证），那是现在完全空白、却最接近「这本书为什么能火」的地方。
