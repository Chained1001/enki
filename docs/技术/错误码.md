# 错误码（book-breakdown）

本文件是 `skills/book-breakdown/scripts/` 报出的项目专属错误码的唯一定义处。通用错误码（CLI 参数、技能结构／frontmatter／链接、`init-skill`／`install-hooks` 等）见 `docs/规范/02-脚本与测试.md`，两表不重复登记。

`--json` 输出的 `errors[]` 每项含 `code`、`message`，有明确归属文件时加 `file`。`E_` 开头是错误，`W_` 开头是警告（不改变交付判定）。新增或改动错误码须同次改本表与 `test/error-codes.test.mjs`。

| 码 | 含义 | 修法 |
|---|---|---|
| `E_ACTS` | 幕纲覆盖不对：网文某卷在交付模式没有幕纲文件；出版书幕纲总份数不等于原文单元数 | 按卷补幕纲；出版书按原文单元逐份建，份数应等于该卷原文单元数 |
| `E_ACT_COVER` | 卷纲「事件弧清单」的弧数与该卷幕纲份数不等（仅网文） | 补齐或删减幕纲，或改卷纲弧清单，使两边相等 |
| `E_ARC_SPAN` | 同一弧名在卷纲「事件弧清单」与幕纲「起止章」两处写的起止章不等 | 对齐两处；消息里已写出卷纲侧与幕纲侧各自的值 |
| `E_BATCH` | `progress --batch-done` 指定的卷号／批号在 `manifest.batches` 中不存在 | 核对卷号与批号，只更新 manifest 里已有的批次 |
| `E_CARD_FIELD` | 卡片缺模板定义的字段标签，或标签在但值为空 | 照 `assets/` 对应卡模板补齐；确实无内容时写「无（第 N 章）」 |
| `E_CHAPTER` | `prepare` 未识别到章节标题，或章节数少于阈值（停止不猜）；`write-rows` 输入章号不是非负整数，或逐章记录里没有该章的行 | 确认原文含「第N章／幕／节／回」「序章」「楔子」等标题行；章号改为非负整数，并先在逐章记录建好该行 |
| `E_CHARCOUNT` | 逐章记录「章字数」列不是正整数，或与 manifest 记录的 `chars` 不一致 | 该列由脚本填：重跑 prepare／write-rows；不要手改，也不要填估算值 |
| `E_COLUMN` | 产物表的表头与 `COLUMNS` 契约不一致，或缺整张表／整个小节。覆盖分卷总表、逐章记录、伏笔台账、别名词典、人物关系、人物索引、集合索引，以及快速报告的人物／设定／情节线／技法四表 | 照契约列名逐字改。列名逐字比对，改一个字（「首次出现」→「首现」）就报。报告四表按内容认（含 `### 人物` 小节）而不写死路径 |
| `E_CONFLICT` | manifest 在读取与写盘之间被其他进程修改：`progress` 写前复核 mtime 不一致，`cost` 连续 3 次内容变化 | 重试；不要并发写同一产物目录，也不要手改 manifest |
| `E_CONTRACT` | `volume-stats` 写分卷总表时找不到契约要求的「卷」或「爽点密度」列 | 按 `contract.mjs` 的列名补表头 |
| `E_COST_MISSING` | `cost --check` 时 manifest 没有成本计量（`cost.total.calls` 为 0） | 在各阶段用 `--record` 上报用量 |
| `E_DUP` | `write-rows` 输入里章号重复 | 每个章号只留一条输入 |
| `E_ENCODING` | `prepare` 读原文时既不能按 UTF-8 也不能按 GBK 解码 | 先把原文转为 UTF-8 再试 |
| `E_ENUM` | 取值不在 `contract.mjs` 的 `ENUMS` 内：逐章记录的情绪／章末钩型／爽点强度／爽点类型、伏笔台账的类型／重要度、幕纲峰值强度，或 `write-rows` 的枚举字段 | 改成合法枚举值（可带说明，但须以枚举值开头）；消息里列出该字段的合法取值 |
| `E_FIELD` | `write-rows` 输入缺字段、仍是「（待填）」占位、含竖线或换行 | 补齐字段；竖线改全角「｜」；去掉换行；只补部分列加 `--partial` |
| `E_FILE` | 文件不存在或读不到：`progress --file` 指定的产物文件不存在；`reconcile` 读不到报告；`volume-stats` 读不到逐章记录或分卷总表 | 核对产物根相对路径（不接受 `..` 与绝对路径）；先跑 prepare 生成骨架；报告路径让用户确认，不要退回手算 |
| `E_FORCE_CONFIRM` | `prepare --force` 没有同时给 `--i-know`。消息里写出「多少个已填文件需要重做」、前几个文件名与归档路径（`_旧N`）。退出码 2（参数错） | 把这条消息原样转述给用户，等他确认后加 `--i-know` 再跑。不要自己补上——那句确认是给人看的 |
| `E_FORESHADOW` | 伏笔台账编号不是 `F001` 起的连续编号，状态未以「未收／半收／已收／续作预留」开头，或回收章早于埋点章 | 按 `F001` 起重排编号；状态用合法枚举；回收／引爆章不得早于埋点章 |
| `E_FORESHADOW_REF` | 产物引用了伏笔台账「编号」列里不存在的 `F01-01` 形态编号（按文件汇总报一条） | 补进台账，或改掉错号。台账还没登记任何编号时不检查（否则全书引用都会被判悬空） |
| `E_HEADER` | 表头与契约不符：主台账或增量文件的列数／首列名不对；`volume-stats` 找不到逐章记录或分卷总表表头；`write-rows` 找不到逐章记录表头 | 表头必须与 `contract.mjs` 的 `COLUMNS` 逐字一致。脚本不猜列序——列序错了会把描述写进类型列 |
| `E_INDEX` | 集合索引与条目文件对不上：索引行数不等于条目数、索引路径不存在、主角文件夹缺五文件之一、关系表端点不在人物索引中（交付模式的空集合也报此码） | 建卡并登记索引，交付前清掉空集合；索引路径写产物根相对路径；主角补齐五份文件；关系表端点先登记进人物索引。README 技能表缺行报 `E_README_INDEX`，见 02 |
| `E_INDEX_MISSING` | `reference-index --check` 找不到 `索引.md` | 运行 `node reference-index.mjs --write` 生成 |
| `E_INDEX_STALE` | `reference-index --check` 发现 `索引.md` 与实际文件不一致（有文件增删或改了小标题） | 运行 `--write` 重新生成 |
| `E_INPUT` | `prepare` 的原文路径不存在、不是文件、不是 `.txt`，或原文为空 | 给一个存在的非空 `.txt` 原文路径 |
| `E_INPUT_IN_OUTPUT` | `prepare` 的输入文件落在既有产物目录的 `原文/` 内，会自我嵌套 | 把源文件放到产物目录外 |
| `E_INTERNAL` | 脚本未捕获异常的兜底：打印 stack 并以 1 退出 | 按 stack 定位；这是脚本缺陷，附复现步骤报 issue |
| `E_LEDGER` | `merge-foreshadow` 找不到 `故事底本/故事剧情/伏笔台账.md` | 先跑 prepare 生成骨架；台账缺失时无法判断哪些编号已存在，拒绝猜 |
| `E_MANIFEST` | `manifest.json` 不可读、损坏、必填字段（`chapterCount`／`volumes`／`chapters`）不完整，或产物目录缺少 manifest | 先跑 prepare；损坏或字段不全用 `prepare --force` 归档重建 |
| `E_MERGE` | `merge-foreshadow` 的兜底码：抛出的错误自己没定码（参数错、增量文件读不了等）时用它 | 消息本身就是说明，按它改。有专属码的场合优先报专属码（台账缺失 `E_LEDGER`、表头不符 `E_HEADER`） |
| `E_NOT_FOUND` | 查询类命令没有找到目标：实体不在索引里、引句在全书未命中、或指定章没有任何命中的引句 | 核对名称/别称与产物内容；确认阶段 4 已完成；这不是参数错（参数错报 E_ARGS） |
| `E_PREPARE` | `prepare` 的兜底码：抛出的 `UsageError` 未带具体码时用它 | 按消息改；具体场景优先报专属码（`E_INPUT`、`E_CHAPTER`、`E_ENCODING` 等） |
| `E_PROGRESS` | `progress` 的兜底码：抛出的 `UsageError` 未带具体码时用它 | 按消息改；参数问题优先报 `E_ARGS`，manifest 问题报 `E_MANIFEST` |
| `E_ROW_COUNT` | 逐章记录的数据行数不等于 `manifest.chapterCount` | 按章数补齐或删行，一章一行 |
| `E_SECTION` | 固定 Markdown 产物缺契约要求的段名 | 照模板补段名（标题文字须逐字一致） |
| `E_SOURCE` | 列表项结论缺「第 N 章」出处（按文件汇总报一条） | 补章号与原文引句；为消警告去编章号会变成本码 |
| `E_SOURCE_CHANGED` | 续跑时源文件 `sha256` 与 manifest 记录不一致 | 确认换了源文件后用 `prepare --force` 重拆（旧目录归档），或换回原文件 |
| `E_STAGE` | `progress --stage` 的阶段号不存在，或状态不在 `ENUMS.阶段状态` 内 | 用 manifest 里存在的阶段号与合法状态 |
| `E_TOPIC` | 专题缺「涉及判定」结论，或判定取值未以「涉及／弱涉及／本题材不涉及」开头 | 补判定行；说明写在依据行，不要把说明并进判定值 |
| `E_TREE_EXTRA` | 产物目录里有不属于契约的文件（目录外文件一律不属于产物） | 删掉或移出；只保留契约文件与原文 |
| `E_TREE_MISSING` | 产物缺契约固定文件 | 按 `contract.mjs` 的 `productPlan` 补齐；可重跑 prepare 生成骨架 |
| `E_UNFILLED` | 交付模式下文件仍含「（待填）」占位 | 填完内容；进度模式只算未完成，不报此错 |
| `E_VOLUME_MISSING` | 出版书某卷没有卷纲文件，或该卷一份幕纲都没有（进度模式下降为 `W_VOLUME_MISSING`，因为「还没做」不等于「做错了」） | 补该卷卷纲与该卷各原文单元的幕纲。出版书幕＝原文单元，幕纲份数应等于该卷的原文单元数 |
| `W_ACTS` | 网文某卷尚无幕纲文件（进度模式），或该卷幕数超出常见区间 2–6 | 补幕纲；幕数异常时记例外说明。只警告不阻断 |
| `W_ACT_HOOK` | 相邻两幕「上一幕出口情绪」与「这一幕入幕情绪」取值相同，且两幕的「情绪基调与走向」段都没写承接说明 | 补一句承接理由（出现「承接／衔接／落差／连场」等字样即消），或复核其中一处情绪取值。只警告不改判定：情绪走势合理与否要看剧情 |
| `W_ARC_REF` | 卷纲「事件弧清单」缺「弧号」列，或幕纲「与卷纲的对应」段缺弧号、弧号在卷纲弧清单中不存在 | 补 `A01` 起连续的弧号，并让幕纲引用与卷纲对齐。只警告 |
| `W_CONTRACT_VERSION` | `manifest.contractVersion` 缺失或与校验器版本不一致 | 仅作提示，不改判定：旧产物的报错需逐条判断是契约变更还是真缺陷 |
| `W_COST_STAGE_MISSING` | `cost` 报告时阶段 3–7 中有阶段没有任何用量记录 | 用 `--record` 补记；只警告，不阻断 |
| `W_COST_UNDER` | 阶段 4 上报输入低于确定性下界，疑似漏记 | 补记，或核对上报口径；只警告 |
| `W_FIRST_SEEN` | 人物卡的「首次出场章」与别名词典同主名的「首次出现章」不一致，或卡主名不在词典主名列中 | 对齐两处；主名不在词典里时先把人登记进词典 |
| `W_INDEX` | 集合索引条目路径用了集合相对路径（本次容错通过），或路径不在其类型子目录下 | 改成产物根相对路径，并放进对应类型子目录 |
| `W_INDEX_EMPTY` | 进度模式下集合索引 0 行且无任何条目卡——属「还没做」，交付模式下同一情形报 `E_INDEX` | 建卡并登记索引；交付前必须清掉 |
| `W_LINE_GAP` | 逐章记录里某条剧情线连续缺席超过阈值 | 补该线的章节记录，或确认它已收束；只警告 |
| `W_NO_COST` | 金手指「代价与限制」段写「无」，但段内没有依据章号 | 补一句（第 N 章「原文」），或复核是否真无代价。只警告：真的无代价是合法的少数设定 |
| `W_PROSE` | 结论以散文段落写出且嵌原文引句的覆盖率不足（按文件汇总报一次，不逐行刷屏） | 给散文结论补原文引句，或改成带出处的列表项 |
| `W_PROSE_NOSRC` | 散文结论没写「第 N 章」出处。这类行仍计入散文分母，所以 `W_PROSE` 的百分比会因它而降低 | 补章号；若是概括整卷走向、确实不落在单章的话，保留散文写法即可——只警告不阻断。别为了消警告去编章号，那会变成 `E_SOURCE` |
| `W_QUOTE` | 引述型结论中带原文引句的比例低于阈值 | 补原文引句；只警告，抽读时核对 |
| `W_QUOTE_WEAK` | 引号内的引句不含任何具体名词（人名／地名／器物／数字），换个书名照样成立 | 换一条带本作专名的引句；确实是靠语气取胜的句子可保留，此警告不影响交付 |
| `W_SHARP_TYPE` | 逐章记录的「爽点强度」填了非「无」的值，但「爽点类型」空着。类型只在强度为「无」时才可空 | 补「爽点类型」（打脸／逆袭／获得／解惑／情感／奇观）。只警告不阻断 |
| `W_STALE_MARK` | 卷纲已存在，某文件里仍写着「第 N 卷尚未拆解」这类过期标注 | 更新状态说明。只管状态文字，不判产物内容 |
| `W_STATE_DRIFT` | `manifest.files` 记的状态与磁盘内容不符：文件已无「（待填）」占位却仍记 `skeleton`，或文件还有占位却记 `done`／`filled`。逐条最多报 5 条，其余汇总成一条 | 更新 `manifest.files`，或把该文件补完。只警告不改判定 |
| `W_TABLE_STALE` | 分卷总表某个叙述列几乎把卷纲对应段整段的字保留了下来（重合 ≥ 85%），是照抄而非压缩 | 把该格压成关键词。只警告不阻断：照抄不算错，但那等于白填一列。只查「照抄」这一个方向 |
| `W_TOPIC` | 专题判定为「本题材不涉及」但没写承接槽位（指向） | 补「- 指向：…」。只警告 |
| `W_VOLUME_MISSING` | 进度模式下出版书某卷没有卷纲，或该卷没有幕纲（交付模式的同一情形报 `E_VOLUME_MISSING`） | 补该卷卷纲与各原文单元的幕纲 |
