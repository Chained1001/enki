# 规范来源

本文件登记 `docs/规范/` 每份标准的来源、借鉴内容与偏离。规范正文以各文件为准；本文件只记账，不复制规则，也不参与编号。

- 来源分三类：上游 0.5.4（`辅助内容/开发框架/规范/`）、外部标准、本项目原创。
- 「偏离」按 `git diff --no-index` 与上游同名文件逐份比对核实（2026-10-26）。上游只作参考实现，不构成权威。
- 修改标准时同次更新本表；新增标准必须登记，`test/standards.test.mjs` 检查本表覆盖全部标准。
