# 专题模板

## 概念

- 定义：单一设定子域的深挖文档。六个槽位常驻：力量体系／成长与资源体系／历史年表／地理图志／时代参照层／规则与铁则，每书六份全部生成。
- 目的：把世界观概览装不下的体系性设定独立成库；「本题材不涉及」的空槽判定本身是题材信息，并指向承接槽位。
- 边界：世界规则的概览归世界观单体；金手指归必选单体；实体条目归五集合。

## 契约

- 填写者：技能（结构化模式）。
- 条款：项目 PRD 的 F-09、Q-14、Q-20、Q-24。文件名取槽位名，如「力量体系」。（项目 PRD 不随技能下发，此处仅作编号索引；判据以 references/ 与同目录模板为准）

## 内容

每个槽位文件的第一行是涉及判定，之后按判定走两种形态之一。段名一律写成 `##` 或 `###` 标题，标题文字与段名逐字相同、不加括号后缀——校验器按标题全等比对，少一个字或多一个后缀都判缺段。

### 涉及判定

- 判定：涉及／弱涉及／本题材不涉及（只填枚举值开头，限定范围等说明写在依据行）
- 依据：（一句原文证据或题材判断，涉及与弱涉及必填出处）
- 指向：（不涉及或弱涉及时，写明承接槽位，如「本题材不涉及，成长与资源承接」）

### 形态一：涉及（完整五段）

本形态的五个段名即下列五个 `###` 标题，不是列表条目。

### 定义与范围

（覆盖什么、不覆盖什么）

### 结构与层级

（等级阶梯、分类树、编年段等，按槽位形态组织）

### 揭示节奏

（引入章→系统化章→补完章）

### 与剧情的耦合

（关键设定点驱动了哪些卷、幕；主角相关节点带章号）

### 与其他设定的边界

（指向世界观、金手指、概念集合的分工，一句一条）

### 形态二：本题材不涉及（只写三行）

判定行＋依据行＋指向行，不展开段落；上一组五段标题整段删除。

### 六个槽位的职责

| 槽位 | 职责 | 弱涉及时的对应槽位 |
|---|---|---|
| 力量体系 | 世界公共修炼/能力规则：门槛（怎么入门）／通道（怎么升级）／天花板（顶在哪、每层新冲突）三变量＋代价 | 无力量题材→成长与资源体系 |
| 成长与资源体系 | 主角阶段性成长与资源系统：事业阶段表、人脉网络、先知/资源事件清单 | 力量题材→力量体系（本槽位弱涉及） |
| 历史年表 | 世界史双时序：揭示顺序 vs 真实时序 | 现代都市→时代参照层 |
| 地理图志 | 空间规则与地图：区域、通道、禁地 | 单城故事→世界观「地理格局」段 |
| 时代参照层 | 真实年代、品牌与事件参照清单（年代文、都市文重） | 架空题材→不涉及 |
| 规则与铁则 | 不可违反的世界约束及违反案例 | 无特殊铁则→世界观「世界规则要点」段 |
