# 全书大纲模板

## 概念

- 定义：整本书如何搭起来的全书层结构俯视图——先是故事设计书，再是骨架，不是剧情梗概。
- 目的：只看本文件就能回答「这本书怎么搭的」：讲什么、谁的故事、靠什么装置驱动、分几个大段、九个经典节点落在哪。
- 边界：不写卷内情节细节（归卷纲与幕纲），不写设定条目（归设定库）。

## 契约

- 填写者：技能（结构化模式）。
- 条款：项目 PRD 的 F-05、Q-01、Q-24。（项目 PRD 不随技能下发，此处仅作编号索引；判据以 references/ 与同目录模板为准）

### 故事设计

编辑看大纲的前几个问题在本块作答，七项各一行：

- 主题母题：（一句话：这本书想说什么）
- 主角 logline：（谁·要什么·卡在哪）
- 核心欲望与恐惧：（全书所有情节的发动机）
- 主要对手与对抗结构：（谁在阻止，对抗怎么升级）
- 弧光终点：（起点→终点一句话）
- 读者承诺：（读者点进来期待什么；兑现账记在各卷卷纲的「卷末收束与悬念定格」段，本处只记许下了什么）
