# 世界观模板

## 概念

- 定义：世界规则的概览层——世界是什么、怎么运转的一页地图。
- 目的：三十秒建立对世界的基本认知，并作为入口指向深入的专题槽位与集合条目。
- 边界：子域深挖归六个专题槽位；实体条目（人物、地点等）归五集合；本文件只做概览。

## 契约

- 填写者：技能（结构化模式）。
- 条款：项目 PRD 的 F-09。（项目 PRD 不随技能下发，此处仅作编号索引；判据以 references/ 与同目录模板为准）
