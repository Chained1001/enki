# 幕纲模板

## 概念

- 定义：单幕的执行级纲要。幕＝卷内事件弧（案件、战役、婚事、探索、关系阶段等一个完整事件单元）。
- 目的：展示一个事件弧如何从发现走到结算、幕末钩子如何接入下一幕——这是网文节奏的最小可仿写单元。
- 边界：不逐场景展开（名场面列表除外）；卷级统筹与弧的编排归卷纲。

## 契约

- 填写者：技能（结构化模式）。
- 条款：项目 PRD 的 F-08、Q-03、Q-17、Q-23、Q-24；判据见 `../references/判据/幕边界判据.md`。出版书幕＝原文单元，幕纲挂在所属卷纲下，仍需按幕内小节拆五拍（拍落在章内相对位置，见幕边界判据的粒度档位）。（项目 PRD 不随技能下发，此处仅作编号索引；判据以 references/ 与同目录模板为准）

### 幕目标

### 对手与对抗

（本幕对手是谁、强弱对比、对抗方式；对手可空——情感流无外敌时写压力源。一个事件弧的本质就是「主角 vs 谁／vs 什么」）

### 核心事件链

（三～五拍：发现→筹备→反转→爆发→结算；附名场面列表，每条带「第 N 章」）

（本幕新登场、退场、死亡的角色，各带章号）

### 地点与时段

（地点；时段标记：学期、节日、季节等天然界）

### 主角所得与所失

（能力/认知·物品·关系三轴，得到与失去并存——弧光成立的检验是「得到与失去并存」，必须写失去什么；力量文写境界，历史/都市文写认知与威望）

### 幕末钩子

（引出下一幕的悬念或情绪定格，带章号）

### 情绪基调与走向

（入幕／幕中峰值／出口三锚点，基调取值见契约 `ENUMS.情绪`（扬／抑／震荡）；峰值注记取值见 `ENUMS.峰值强度`（爽／燃／虐／喜），**它是独立字段、不是情绪的第四个值**，不与基调做映射；本幕爽点兑现点：读者在这一幕得到了什么满足）
