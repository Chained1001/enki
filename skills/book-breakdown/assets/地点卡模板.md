# 地点卡模板

## 概念

- 定义：单个地点的档案，灵魂字段是空间规则（该地点区别于常规空间的规则）。
- 目的：脱离原文仍能调用该地点的功能、规则与剧情关联。
- 边界：区域级格局归世界观与地理图志槽位；发生在地点的事件归卷纲幕纲。

## 契约

- 填写者：技能（结构化模式）。
- 条款：项目 PRD 的 F-09、Q-12。（项目 PRD 不随技能下发，此处仅作编号索引；判据以 references/ 与同目录模板为准）

## 内容

- 名称：
- 别名与真名揭示章：
- 所属区域：
- 功能与象征意义：
- 空间规则：（该地点区别于常规空间的规则；无则写「常规」）
- 关联人物与势力：
- 首次出场章：
- 进入章：（主角实际进入的章；预告章≠进入章，分列）
- 状态轨迹：（损毁、易主、功能变化，带章号）
