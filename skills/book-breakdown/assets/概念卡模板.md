# 概念卡模板

## 概念

- 定义：单个概念的小规则库——定义、规则细节与揭示节奏。
- 目的：网文的核心设定（序列、修罗场、气运）往往就是一个概念撑起的；本卡让它脱离原文仍可被引用和复用。
- 边界：体系级结构（整条力量体系、整段历史）归专题槽位；本卡只管单一概念。

- 填写者：技能（结构化模式）。
