# 人物卡模板

## 概念

- 定义：单个角色的可复用档案。次要角色用基础卡；主要配角在基础卡后追加五段深化。
- 目的：脱离原文仍能调用这个角色——查设定、复用人物设计、核对关系。
- 边界：主角不用本卡（归主角解构文件夹）；人物之间的关系结构归关系表与索引。

## 契约

- 填写者：技能（结构化模式）。
- 条款：项目 PRD 的 F-09、F-15、Q-19、Q-24。（项目 PRD 不随技能下发，此处仅作编号索引；判据以 references/ 与同目录模板为准）

## 内容（基础卡）

- 姓名（主名）：
- 别称与马甲：（一一挂首次章）
- 归属势力：
- 力量/成长坐标：（境界链或事业阶段，带章号锚点）
- 首次出场章：
- 关键章节链：（3-6 个节点）
- 核心关系：
- 说话风格与人设锚点：
- 体貌锚点：（原文怎么写这个人的长相、年龄、身材；无则写「无」，不得推断。带「第 N 章」出处）
- 衣着与装束：（原文怎么写他穿什么；常服与盛装分记。无则写「无」。带「第 N 章」出处）
- 神态与动作锚：（他的固定表情、小动作、生理反应——**同一细节复现 2 次以上才记**，单次形容不收。无则写「无」。带「第 N 章」出处）
- 外在目标（要什么）：带「第 N 章」出处
- 内在缺口（缺什么）：他为什么非要不可，带「第 N 章」出处
- 致命弱点（会毁在哪）：带「第 N 章」出处
- 原型词：（如白月光、宝藏、告密者）自由填，不校验
- 功能位：导师／镜子／压力源／氛围／线索人／对手／工具人（闭合枚举，见 `contract.mjs` 的 `ENUMS.功能位`；只能填其中一个）
- 结局状态与死亡/退场章：（未完本或仍在世时写「在世（未完）」并注最后已知章）
- 金句锚：（至少一句可检索原文，带章号）

三要素齐则人物卡立得住：外在目标／内在缺口／致命弱点缺一项即未完成（人物提炼 S-01）。

## 前四卷补全

> 建卡只读到「该角色出场的前四卷」为止。四卷之后的变化用回填结构记，不要把整本书读完再写一张卡。
> 回填时只补**变化的部分**，并注明出自第几卷；没变化的字段留初始取值，写「（后四卷无变化）」。
