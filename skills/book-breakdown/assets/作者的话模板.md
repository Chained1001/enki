# 作者的话模板

## 概念

- 定义：从正文剥离的**结构相关**作者附注（卷末总结、完本感言、结构预告），归集为「作者自述」。例行附注（求票/打赏/请假）在预处理丢弃，仅计数——见 PRD Q-25。
- 目的：提供一手的结构证据：作者对各卷结构的定性、方法论、人物结局交代与续作接口——部名与结构自述常出自此处。
- 边界：不是正文内容；正文归 `原文/`。

## 契约

- 填写者：技能（预处理剥离＋归集）。
- 条款：项目 PRD 的 F-22。无附注时全文件只写「无」。（项目 PRD 不随技能下发，此处仅作编号索引；判据以 references/ 与同目录模板为准）

## 内容

### 结构自述

（作者对各卷/部结构的定性，逐条带出处章或行号）

### 方法论

（作者自述的写作方法：伏笔纪律、节奏、升级即工具等）

### 人物结局交代

（完本感言类附注中的逐人结局）

### 续作接口

（留给续作的伏笔与声明）
