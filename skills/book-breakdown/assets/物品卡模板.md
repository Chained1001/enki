# 物品卡模板

## 概念

- 定义：单个物品的档案，含能力、代价与流转链。
- 目的：脱离原文仍能调用该物品——情感文的关键道具（信物）与玄幻的神兵等价，都是剧情杠杆。
- 边界：成体系的物品规则归专题槽位（力量体系、成长与资源体系）。

## 契约

- 填写者：技能（结构化模式）。
- 条款：项目 PRD 的 F-09、Q-12、Q-24。（项目 PRD 不随技能下发，此处仅作编号索引；判据以 references/ 与同目录模板为准）
