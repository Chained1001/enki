# 开篇三章模板

## 概念

- 定义：全书前三个叙事单元（网文为前三章；出版书为前三个原文单元，如「第N幕」）的逐章深度拆解。出版书下本模板的「章」一律读作「幕」（第一章＝第一幕、章末钩＝幕末钩）。
- 目的：开篇决定签约与留存（「黄金三章」是行业共识），这是作者最常向别人学的一块；拆到可仿写的粒度——钩子怎么下、信息投放节奏、人设怎么立、章末钩怎么接。
- 边界：不重复全书大纲「九节点检查单」里的开篇钩子（那里只做一行定位）；前三章之后的结构归骨架段清单与幕纲。

## 契约

- 填写者：技能（结构化模式，阶段 3 口径锚定时一并完成——只读三个单元，成本低）。
- 条款：项目 PRD 的 F-24、Q-21、Q-24。（项目 PRD 不随技能下发，此处仅作编号索引；判据以 references/ 与同目录模板为准）
