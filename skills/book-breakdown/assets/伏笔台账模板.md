# 伏笔台账模板

## 概念

- 定义：全书伏笔的生命周期账本——每条伏笔从埋下、强化到回收的完整记录。
- 目的：让跨度可达千章的伏笔可追溯、可对账，支撑「学这本书的伏笔布局」场景。
- 边界：不评价伏笔好坏；伏笔发生的剧情上下文归卷纲与幕纲，本表只记账。

## 契约

- 填写者：技能（结构化模式）；优先从复盘章（反派视角整章复盘、卷末总述类）反填，再回溯埋点。
- 条款：项目 PRD 的 F-19、Q-23。（项目 PRD 不随技能下发，此处仅作编号索引；判据以 references/ 与同目录模板为准）

## 内容

| 编号 | 描述 | 类型 | 埋点章 | 强化章 | 回收/引爆章 | 回收幕 | 跨度 | 涉及实体 | 重要度 | 状态 |
|---|---|---|---|---|---|---|---|---|---|---|
| F001 | | 道具／身份／情感／设定／事件 | | | | 幕号或弧号 | 章数差，脚本算 | 指向设定卡 | 主线／支线／边角 | 未收／半收／已收／续作预留 |

- 编号从 F001 起连续；埋点章、强化章可多个，逗号分隔。
- 章号列只填数字章号（全局章号）；未能核实的写「未核」并注明推断依据。
- 类型取值：道具／身份／情感／设定／事件——埋法与回收方式随类型不同（如台灯是道具伏笔，马甲是身份伏笔），写枚举值开头。
- 回收幕填回收发生的幕号或卷纲弧号（如「卷01-幕02」「A03」），让台账与幕纲可对账；未收的留空。
- 重要度取值：主线／支线／边角——主线大伏笔与边角料分开记，写枚举值开头。
- 状态列只填枚举值开头（未收／半收／已收／续作预留），补充说明写在描述列，不塞进状态列。
- 涉及实体写实体主名，与设定库文件名一致。
- 跨度＝最早埋点章至最终回收章的差（多次回收取最终回收章）；未收的留空。

非常规叙事书（认知翻转、双重世界）追加三列：多层兑现（同一伏笔分层回收，逐层记章号）、揭示即反转（兑现本身重写前文意义的记「是」及影响范围）、读者可知性（埋点时读者能否察觉）。
