# 势力卡模板

## 概念

- 定义：单个势力或组织的档案。
- 目的：脱离原文仍能调用该组织的性质、结构、成员与立场演变；类型含现代组织（公司、学校）与信息网络（跨势力群聊）。
- 边界：成员的个人档案归人物集合；跨组织的公共规则归专题槽位。

## 契约

- 填写者：技能（结构化模式）。
- 条款：项目 PRD 的 F-09、Q-12、Q-24。（项目 PRD 不随技能下发，此处仅作编号索引；判据以 references/ 与同目录模板为准）
