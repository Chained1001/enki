# 解读提示

> **本文件不作为判定依据。**
>
> 这些是**作者自查题**：写的时候拿来问自己「我这段是不是漏了什么」，不是拆书时判定对错的依据。
> 它们大多以「吗？」结尾、要求的是作者对自己意图的了解，而拆书者手里只有原文——
> 回答「反派和主角是镜像关系吗？」需要知道作者想写什么，原文只能证明「写了什么」。
> 把这类问题当判据，会让 agent 在不可判定的事上编出结论，也可能反过来逼着它把有缺陷的书判成合格。
>
> 判据（可判定、有阈值、读文本就能答的）留在 `references/*策略.md` 的判据表与「判断标准」段的可判定句里。
> 本文件的每一条都曾是判据文件里的复选框，现在搬到这里，原位置不再保留。

## 怎么用

- **拆书（agent）**：不读本文件做判定。要判「这个配角有没有功能」，用人物提炼策略里的判据表（J- 项，带强度与判定方法）。
- **对照（人）**：写自己的书时逐条过一遍，勾不上的地方就是可以改的地方。
- **报告里引用**：可以引用本文件的条目作为「作者视角的提醒」，但必须标成解读而非判定结论。

#### 二、读者凭什么跟百万字

#### 四、感情线怎么写不尬

- [ ] 有足够强的屏障吗？（身份对立/目标冲突/外部阻力）
- [ ] 推拉节奏平衡吗？（试探→靠近→回避→爆发）
- [ ] 感情线影响剧情了吗？

#### 五、配角与群像

- [ ] 每个配角有不可替代的功能吗？
- [ ] 配角有自己的独立动机吗？
- [ ] 主角离开后他还想干什么？

#### 五、配角与群像

- [ ] 每个配角的出现都有目的、都在推动主线吗？
- [ ] 配角数量适中吗？多到读者记不住就是浪费笔墨
- [ ] 次情节的主人公有没有抢走太多移情？

#### 五、配角与群像

#### 五、配角与群像

- [ ] 关系有动态变化吗？

#### 八、反派：三层与强度

- [ ] 从反派的视角看，他是对的吗？
- [ ] 反派中段赢过至少一次吗？
- [ ] 反派和主角是镜像关系吗？（他是主角走错一步会成为的那个人吗？）
- [ ] 反派的存活周期配对了吗？（炮灰／阶段／长期／幕后BOSS 四档怎么选、怎么配，见路径表）（小弥写小说#27）

#### 八、反派：三层与强度

- [ ] 反派的力量和主角匹配吗？是不是还略占优势？
- [ ] 主角是靠反派犯低级错误赢的，还是靠绝境里的微小变数/惨烈牺牲赢的？
- [ ] 这一场是“艰难赢过”还是“轻松碾压”？

#### 身份与欲望的五要素自检

- [ ] 基本信息有了吗？（姓名、年龄、社会关系——人物名片）
- [ ] 身份职业定了吗？（它决定他面对什么场景：学生对应学校，警察对应案件）
- [ ] 性格目的有了吗？（决定他遭遇事件时怎么反应）
- [ ] 能力特长挂钩剧情了吗？（三个功能：解决问题、过程精彩、读者期待）
- [ ] 经历过往埋了吗？（他为什么这么做——设定时先埋着，需要时拿出来当转折）
