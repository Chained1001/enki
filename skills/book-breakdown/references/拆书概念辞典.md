# 拆书概念辞典

## 适用范围

拆书全流程共享的术语定义。首次接触某概念时查本件；判定标准在各判据件，操作方法在各策略件。

## 内容

| 编号 | 概念 | 定义 | 依据 |
|---|---|---|---|
| K-01 | 三幕结构 | 建置—对抗—结局的大骨架，幕间以「不可回头的门」分隔，比例约 1:2:1 | E-01 |
| K-02 | 两扇门 | 第一扇门＝主角主动或被迫踏入主线；第二扇门＝不可逆转折；穿过后无法回头 | E-01 |
| K-03 | 激励事件 | 打破人物生活平衡、把主角送上求索之路的事件；每卷可有卷级激励 | E-02 |
| K-04 | 鸿沟 | 人物行动时的预期与实际结果之间的落差；真冲突的最小单元 | E-02 |
| K-05 | 中点 | 全书正中改变世界状态的转折，分假胜利与假失败两形态 | E-01 |
| K-06 | 节拍表 | 救猫咪的 15 拍结构清单；拆书中作对照检查单，不作硬模板 | E-03 |
| K-07 | 事件弧 | 卷内一个完整事件单元（案件/战役/婚事/探索/关系阶段），幕的操作定义 | E-04 |
| K-08 | 五拍 | 事件弧的内部节律：发现→筹备→反转→爆发→结算 | E-04 |
| K-09 | 一级循环 | 单元故事重复模式不重复内容的循环模板（打脸/西游式/升级/探案等） | E-05 |
| K-10 | 黄金三章 | 开篇前三章决定签约与留存的行业共识；对应产物「开篇三章」 | E-06 |
| K-11 | 章末钩 | 章末促使读者点开下一章的悬念设置，分危机/悬念/期待/反差四型 | E-05 |
| K-12 | 钝收 | 高潮后余波章的余韵式收尾；属情绪结算期，连续两章以上才构成拖 | E-05 |
| K-13 | 爽点 | 读者压抑后兑现满足的节拍（打脸/升赏/逆袭）；爽点循环是爽文的骨架 | E-05 |
| K-14 | 期待感 | 读者对下文的预测欲；由信息差、在乎与不确定三者合成 | E-07 |
| K-15 | 信息差 | 作者已知而读者未知的落差；与悬念（已知有危险而不知是什么）相区分 | E-07 |
| K-16 | 情绪兑现 | 前期累积的情绪在后续场景中的支付与结算；钝收章仍须完成本期结算 | E-07 |
| K-17 | 人物弧光 | 人物从起点经崩塌/转折到终点的变化轨迹，成立判据是得到与失去并存 | E-01 |
| K-18 | 契诃夫之枪 | 开篇出现的异常元素后文必须击发的叙事公理；伏笔识别的第一信号 | E-08 |
| K-19 | 红鲱鱼 | 故意埋设用于误导读者的假线索；与真伏笔分档记录 | E-08 |
| K-20 | 换图 | 主角舞台/地图的切换；长篇以换图划分大阶段 | E-01 |
| K-21 | 支线 | 与主线并行、需切线—会合的次级情节线；拆书中记入卷纲事件弧清单 | E-01 |
| K-22 | 群像 | 多角色轮流承视角的写法；拆书记聚光灯轮转与主角缺席段 | E-01 |
| K-23 | 认知水位 | 角色/读者对真相的知情差异三维（知道/不知道/读者先知）；信息差书的独立引擎 | E-09 |
| K-24 | 金手指 | 主角拥有的排他性优势，含知识记忆等非系统形态；判定见金手指判据 | E-10 |
| K-25 | 铁则 | 全书从未打破的宪法级世界规则；与可调整的普通设定分档 | E-01 |

## 依据

- E-01：知识库·方法论（本地库）各对应件（大纲-主线与骨架、人物设计-弧光与关系、世界观-规则与铁则）。
- E-02：麦基《故事》（激励事件、鸿沟；网络公开资料与 novel-deconstruct 调研交叉）。
- E-03：救猫咪节拍表公开资料；speckit 结构框架可切换（speckit）。
- E-04：大奉反推（幕＝事件弧、五拍实证）。
- E-05：知识库·方法论「卷纲-情节类型骨架 §4.4」「章纲-章型与开篇 §6.1」。
- E-06：行业共识与 oh-story 黄金三章方法（oh-story）。
- E-07：知识库·方法论 判据根系·七原语（期待感/信息差/在乎×不确定/代价/动机链/情绪兑现/变化）。
- E-08：契诃夫之枪公理；知识库「大纲-伏笔埋收」红鲱鱼条目。
- E-09：QMAI 认知系统与理论地基 T053（信息差学理出处）。
- E-10：PRD Q-18 与金手指判据。
