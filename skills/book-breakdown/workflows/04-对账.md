# 04 对账

所属技能：book-breakdown。入口见 `../SKILL.md`。

## 目的

检查章节、摘要、要素三者是否对得上，给出可核对的数字。

## 输入

| 字段 | 来源 | 必需 | 缺失时 |
|---|---|---|---|
| 章节列表与字数 | 01 切章 | 是 | 停止，交回入口 |
| 摘要表 | 02 摘要 | 是 | 停止，交回入口 |
| 要素表 | 03 要素 | 是 | 停止，交回入口 |

## 步骤

1. 核对摘要行数等于章节数。产出：结论与差值。
2. 核对每条要素的首次出现章节都在 1 到章节数之间。产出：越界条目列表。
3. 核对各章字数之和等于总字数，允许换行差异。产出：差值。
4. 汇总成对账表。产出：对账表。

## 产出

对账表：项、期望、实际、结论。

## 停止条件

- 任一核对不通过：在报告中标注，交回入口说明，不自动修补。
