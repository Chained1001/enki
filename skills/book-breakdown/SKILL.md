# book-breakdown

## 何时使用

- 用户给出一个 `.txt` 文件路径，要求按章拆解。
- 用户要求从整本小说里提炼人物、设定、情节线与写作技法。

不适用于：单章分析、非小说文本、需要联网抓取的文本。

## 总流程

| 序号 | 步骤组 | 流程文件 |
|---|---|---|
| 01 | 切章 | `workflows/01-切章.md` |
| 02 | 摘要 | `workflows/02-摘要.md` |
| 03 | 要素 | `workflows/03-要素.md` |
| 04 | 对账 | `workflows/04-对账.md` |

按序号依次进入，每个流程文件进入时读取、完成后进入下一组。

## 输入

| 字段 | 类型 | 必需 | 缺失时 |
|---|---|---|---|
| 小说文件路径 | 路径 | 是 | 停止并询问用户 |
| 书名 | 文本 | 否 | 取文件名去掉扩展名 |
| 拆解范围 | 文本 | 否 | 默认全书 |

## 停止条件

- 文件不存在或不是 `.txt`：停止并说明。
- 切章后为 0 章：停止，报告「未识别到章节标题」，不猜。

## 输出

| 产出物 | 格式 | 结构 | 落地路径 |
|---|---|---|---|
| 拆书报告 | Markdown | 见 `assets/报告版式.md` | 由用户指定；未指定时只输出到对话 |
