# book-breakdown 反向仿写：只读已填产物写第三章

## 输入

- 被测技能：skills/book-breakdown
- 指令：只读 `../work_tmp/全流程-长安/长安的荔枝_拆解/`（工作区根，相对 Enki 仓库），不要修改其中任何文件。以该产物为依据，写《长安的荔枝》第三章（标题自拟，正文 1500–2500 字），存到 `辅助内容/测试目录/反向仿写-长安第三章.md`。文件分两段：`## 结构说明`（写明对应哪一卷、哪份幕纲文件与起止章；章末钩型及取自 `工作/逐章记录.md` 的哪一行哪一列；以及「读者已知／主角未知」信息清单及来源）与 `## 正文`。产物只读，不得补写产物；查不到的项写「不可核对」，不得自拟幕号或钩型。
- 样本：`../work_tmp/全流程-长安/长安的荔枝_拆解/`（相对 Enki 仓库；本机样本，不入库；运行前确认存在，不存在则记录跳过，不用骨架冒充）
- 运行方式：人工对话
- 前置状态：主样本为已填产物（`工作/逐章记录.md` 7 行数据（含前言）、`故事底本/故事剧情/幕纲/` 5 份）；`test/fixtures/products/合成小书_拆解/` 是 prepare 骨架，仅作「骨架态不可用于反向仿写」的反例——它的章末钩型列仍是「（待填）」、幕纲目录为空，拿它跑会把「未记录」误判成「一致」，本用例不用它作样本

## 基线

无，理由：本用例首轮建立，当前会话没有可运行的 agent 宿主；运行后按 templates/test-run/ 记录。由人核对。

## 期望

- 产物目录零改动；输出文件含 `## 结构说明` 与 `## 正文`，正文 1500–2500 字。
- 结构说明把第三章定位到 `故事底本/故事剧情/幕纲/卷01-幕02-岭南破法.md`（起止第 2-3 章），卷为 `卷01-全书`。
- 章末钩型取 `工作/逐章记录.md` 第 3 章行（第 10 行）第 11 列，值为 `危机`；正文确实落在危机上。
- 信息清单至少含一条「读者知、李善德不知」的项（`林邑奴是赵欣宁的眼线` 或 `何履光要杀他`），并带幕纲来源行；正文不提前让李善德知道它。
