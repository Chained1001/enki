# book-breakdown 出版书路径：两个原文单元

## 输入

- 被测技能：skills/book-breakdown
- 指令：用 book-breakdown 拆解这本两单元的出版书（`book_type=出版`），按默认的结构化模式；每个原文单元一份幕纲，幕＝原文单元，不拆事件弧。先按下面命令生成样本 `辅助内容/临时文件/出版书2单元.txt`，再用 `--out 辅助内容/测试目录/出版书2单元_拆解` 把产物落到测试目录；按 05–10 走完，最后用交付模式自检并交付。
- 样本：`辅助内容/临时文件/出版书2单元.txt`（2 个原文单元，各约 1.9 万字；本机生成，不入库）
- 运行方式：人工对话
- 前置状态：`辅助内容/临时文件/出版书2单元.txt` 不存在，按下面命令生成；`辅助内容/测试目录/` 下无同名旧产物

样本生成命令（仓库根运行）：

```powershell
node -e "const fs=require('fs');const line='夜里，周野在北站候车厅擦那只铁皮盒，站务组的老秦说末班车不会来。\n';const u=(n,t)=>'第'+n+'幕 '+t+'\n'+line.repeat(600);fs.mkdirSync('辅助内容/临时文件',{recursive:true});fs.writeFileSync('辅助内容/临时文件/出版书2单元.txt',u('一','夜班')+'\n'+u('二','末班'))"
```

样本只为触发「出版书判定」与「卷层／幕层落位」，不用于评价拆解质量；两单元各 600 行同一句，均章约 1.9 万字，`prepare` 会判 `bookType=出版`。

## 基线

无，理由：本用例首轮建立，当前会话没有可运行的 agent 宿主；运行后按 templates/test-run/ 记录。由人核对。

## 期望

- `manifest.json` 记录 `bookType=出版`、2 个原文单元、1 卷。
- 卷层与网文同形：1 份卷纲、1 行分卷总表；幕层按原文单元落 2 份幕纲，文件名 `卷01-幕01-*`、`卷01-幕02-*`。
- 卷纲「事件弧清单」不是网文事件弧，而是一行一个原文单元，弧型列写「原文单元」。
- `validate-output --mode deliver` 退出码 0，固定产物里不再有「（待填）」。

## 判据

| 编号 | 类型 | 判定条件 | 判定方法 | 证据位置 |
|---|---|---|---|---|
| C-01 | 硬性 | `工作/manifest.json` 的 `bookType` 为 `出版`，`chapterCount` 为 2，`volumes` 为 1 卷 | 解析 manifest，逐项核对 | `辅助内容/测试目录/出版书2单元_拆解/工作/manifest.json` |
| C-02 | 硬性 | `故事底本/故事剧情/卷纲/` 恰有 1 份 `.md`，文件名匹配 `卷01-*.md`，且没有第二卷卷纲 | 目录列举并计数 | `辅助内容/测试目录/出版书2单元_拆解/故事底本/故事剧情/卷纲/` |
| C-03 | 硬性 | `故事底本/故事剧情/幕纲/` 恰有 2 份 `.md`，文件名分别为 `卷01-幕01-*.md` 与 `卷01-幕02-*.md`，无 `幕03` | 目录列举并按文件名逐项核对 | `辅助内容/测试目录/出版书2单元_拆解/故事底本/故事剧情/幕纲/` |
| C-04 | 硬性 | 两份幕纲各对应一个原文单元：`幕01` 的「幕定位」或「幕目标」写明「第一幕 夜班」，`幕02` 写明「第二幕 末班」；每份幕纲十二段齐备，并按幕内小节拆五拍，不是只写「本章讲了什么」的章节摘要 | 人工核对：读两份幕纲的前两段、十二个段名与五拍落点 | 两份幕纲文件 |
| C-05 | 硬性 | 产物树按 `productPlan({bookType:'出版'})` 建：`分卷总表.md`、`卷纲/`、`幕纲/` 同时存在，幕纲挂在 `故事底本/故事剧情/幕纲/`；不把「卷」当成网文专有（不因 `bookType=出版` 删掉卷层），目录中也没有 `网文卷/`、`出版书/` 等按书型分叉的名字 | 用 `node -e` 对比 `productPlan` 的 `dirs`/`files` 与磁盘；递归列目录并检索 `网文卷` | `辅助内容/测试目录/命令输出.txt` |
| C-06 | 硬性 | 在产物目录上运行 `node skills/book-breakdown/scripts/validate-output.mjs <产物目录> --mode deliver`，退出码为 0 | 记录命令、stdout 与退出码；stdout 的错误数须为 0（警告不改变退出码） | `辅助内容/测试目录/命令输出.txt` |
| C-07 | 参考 | 卷纲「事件弧清单」恰有 2 行，两行分别对应两个原文单元，弧型列写「原文单元」，不写网文事件弧名（如「探索弧」「决战弧」） | 人工核对：逐行读表，对照 manifest 的两个单元 | `故事底本/故事剧情/卷纲/卷01-*.md` |
| C-08 | 参考 | `开篇三章.md` 按幕读：第一章对应第一幕、第二章对应第二幕；本书只有两个原文单元，第三章写「无（本书仅两个原文单元）」，不编第三幕；可复用套路至少 3 条 | 人工核对：逐章对照单元标题与套路条数 | `故事底本/故事剧情/开篇三章.md` |
