# book-breakdown 脚本用例：prepare 初始化与护栏

## 输入

- 被测技能：skills/book-breakdown
- 指令：运行 `node skills/book-breakdown/scripts/prepare.mjs <样例.txt>`
- 样本：合成三章样例（第一章/第二章/第三章，各含正文与一句对话）；负例为无章节标题的同规模文本
- 运行方式：CLI
- 前置状态：样例放在临时目录

## 期望

- 正例：退出码 0，stdout 含「已准备」；产物目录含 `原文/章节/`、`工作/manifest.json`、全部骨架文件与六个专题槽位。
- 负例：退出码 1，stderr 含「未识别到章节标题」，未建目录。
