# enki

把整本小说 txt 拆成结构化、可校验、可按层复用的拆书产物。给网文作者自己用。

状态：可用（v0.2.0 起支持全书结构化拆解；两种书型已实测：网文《绍宋》433 章全书、出版书《龙族1》）

## 安装

```bash
npx skills add Chained1001/enki
```

前置条件：Node.js 24 及以上。

安装后确认：触发 `book-breakdown`，给一段含三章的小文本，应产出完整产物骨架与摘要。

## 技能列表

| 技能 | 用途 | 扩展键 |
|---|---|---|
| book-breakdown | 整本小说 txt 拆解：默认结构化模式产出 `<书名>_拆解/` 固定目录（四层剧情骨架、伏笔台账、开篇三章、世界观与金手指、六专题、设定五集合、主角解构、文风、作者的话，全部可脚本校验）；快速模式产出单份章节摘要与要素报告 | 无 |

## 两种模式

| 模式 | 产物 | 适合 |
|---|---|---|
| 结构化拆解（默认） | 固定目录树＋骨架先行＋逐层填写＋交付校验，支持断点续跑、按卷并行 | 想按层复用结构与设定 |
| 快速报告 | 一份拆书报告 | 快速概览 |
